# Türk Köyü — Yaşam Simülasyonu

Telefon tarayıcısında oynanan, 2D kuşbakışı bir Türk köyü yaşam simülasyonu.
Tek dosyadır (`index.html`, HTML5 Canvas + JavaScript); kurulum ya da internet gerektirmez.

## Nasıl açılır
- `index.html` dosyasını telefon ya da bilgisayar tarayıcısında aç.
- Ya da GitHub Pages'i aç (Settings → Pages → Branch: `main`, klasör: `/root`); oyun deponun Pages adresinde çalışır.

## Öne çıkanlar
- 100 kişilik başlangıç nüfusu; kişilik ve hayat hedefine göre kendi kararlarını veren köylüler
- Gece-gündüz, mevsimler (kışın kar), 5 gerçek dakika = 1 oyun ayı, hız düğmeleri
- İlişkiler (−100…+100), aile husumetleri, dedikodu, küsme/barışma, kavga, boşanma
- Doğum, okul, askerlik, ölüm ve miras; nesiller boyu süren aile ağacı
- Kız isteme → söz → nişan → kına → düğün; asker uğurlama, cenaze, bayramlar
- Rekabet eden işletmeler, borç ve iflas, köy hazinesi, 5 yılda bir muhtarlık seçimi
- Oyuncu modları: izleyici, karakter yönetme, Tanrı modu
- Her oyun ayında otomatik kayıt (localStorage)
